# Java Day 28 - Count Even and Odd Numbers

This Java program counts even and odd numbers in an integer array.

## Example

Array:
```text
10, 15, 20, 25, 30, 35
```

Output:
```text
Even numbers = 3
Odd numbers = 3
```

## Concepts Used

- Arrays
- `for` loop
- `if-else` statement
- Modulus `%` operator
- Counter variables
- Increment operator `++`

## How It Works

The program checks each array element using the modulus operator. If a number is divisible by 2, the even counter increases. Otherwise, the odd counter increases.
